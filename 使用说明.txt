PCL2 主页自动刷新 · 发布包
================================

包含：

1. PCL主页服务.exe
   本地主页数据服务，地址 http://127.0.0.1:8848/motd.xaml
   已内置 Python 运行环境，目标电脑不需要装 Python。
   重复双击不会多开（检测到已在运行会直接退出）。

2. logo.png
   主页顶部的 IMC 横幅。它必须和 PCL主页服务.exe 放在同一个文件夹里，
   服务会自动把图片发给 PCL；删掉也不影响使用，只是主页顶部没有 Logo。

3. PCL2-主页补丁安装器.exe
   给 PCL 打“主页自动刷新”补丁。
   双击运行 → 自动寻找 PCL 目录（找不到会让你选）→ 备份原程序 → 写入补丁
   → 自动把 PCL 主页设置为本地服务地址（不用手动填）。

4. 安装开机自启.bat / 取消开机自启.bat
   让主页服务随 Windows 登录自动启动 / 取消自动启动。

5. 停止主页服务.bat
   结束后台正在运行的主页服务（占用 8848 端口），换版本或想重开服务时用。

6. 开启毛玻璃.bat / 关闭毛玻璃.bat
   切换主页卡片的样式：毛玻璃（半透明 + 圆角 + 投影）或 PCL 原生白色卡片。
   双击即可，约 1 秒生效，不需要重启服务；实际改的是同目录的 style.txt（内容 glass / classic）。

7. 改版PCL\ 文件夹
   已经打好补丁、并把主页写进预设的启动器，双击就能用，不需要再跑安装器。
   想让 PCL 显示它：设置 → 个性化 → 主页 → 选「预设」→「你知道吗」。
   详细说明见该文件夹里的 说明.txt（含许可提醒：非官方修改版，仅限本地自用）。

8. src\ 文件夹
   主页服务的 Python 源码，方便审查或自行修改。

主页内容
--------
· 毛玻璃风格卡片：半透明底 + 圆角 + 浅色描边 + 柔和投影，能透出 PCL 的背景图
· 顶部 IMC Logo（logo.png，宽度按图片比例自动换算）
· 服务器状态卡：在线人数、MOTD、版本、延迟，每秒刷新（地址用总入口 play.imc.re，数据也从它取）
  刷新方式：主页文本本身固定不变，补丁每秒从 /live.json 取数字、只改写那几个控件，
  所以 PCL 不会重建页面，折叠状态和滚动位置都不会被打断
· 「服务器官网」：整行宽的大按钮，浏览器打开 https://imc.re
· 主页上的按钮统一为蓝色主题，观感一致
· 版本筛选：主页只列出检测为 1.8~1.21.11 的版本（读版本 JSON 的 clientVersion，其次 jar /
  inheritsFrom / id；判断不出真实 MC 版本的，比如某些整合包，一律不显示，用左侧「启动游戏」进）
· 自动加入服务器：点「正版 / 离线」等于带服务器地址启动（PCL 会传 --quickPlayMultiplayer 或
  
  --server），同时在游戏的「多人游戏」列表里自动补上 3 个条目（IMC 总入口 / 离线 / 正版），
  写进 servers.dat（开了版本隔离时每个版本目录各一份，压缩/未压缩格式都保持原样），已有的不重复加；游戏运行时不改动，下次启动生效
· 「按版本进服」：毛玻璃折叠卡，点标题栏可折叠 / 展开（鼠标移上去不会变成蓝色），列出装过的全部版本，
  
  每个版本一组「正版 / 离线」按钮（正版连 on.imc.cab，离线连 off.imc.cab，同一台服务器，
  只是验证方式不同）；服务器支持 1.8–1.21.11，默认版本排在最上面。
  折叠状态会一直保持：页面文本恒定，PCL 不会重建，实时数字由 /live.json 单独更新；
  只有新装或删除了版本（页面结构真的变了），才会重建一次并回到默认展开
· 在线玩家列表（服务器公开时显示）
· QQ 群号一键复制 / 打开加群页

使用步骤
--------
1. 把压缩包解压到一个固定文件夹（不要直接在压缩软件里双击运行）。
   注意 PCL主页服务.exe 和 logo.png 要留在同一个文件夹。

2. 双击 PCL主页服务.exe —— 它没有窗口，会在后台运行。
   也可以双击 启动主页服务.bat：服务没起来就启动它，已经在跑就只提示一句，不会重复开。

3. 双击 PCL2-主页补丁安装器.exe，按提示完成安装。
   安装器会自动把主页地址写进 PCL 设置（PCL\Setup.ini），
   原设置会备份为 Setup.ini.bak。

4. （可选）双击 安装开机自启.bat，这样下次开机服务会自动起来。

5. 打开 PCL，直接进主页即可，数字会自动刷新（默认 0.5 秒一次）。

· 联机卡「联机 · 陶瓦」：直接在主页操控陶瓦联机（Terracotta），不用打开网页
  创建房间 → 陶瓦自动启动 → 进单人存档按 ESC →「对局域网开放」→ 点创建局域网世界
  → 陶瓦生成联机码，自动复制到剪贴板；把码发给朋友
  朋友在输入框填码 → 点「加入房间」即可（会先退回空闲再以访客身份加入）
  「复制联机码」「关闭联机」同理；「打开陶瓦面板」只在需要高级选项时才用
  本机没装陶瓦时，第一次点「创建房间」会自动从官方 GitHub 下载并安装到
  %LOCALAPPDATA%\PCL\Terracotta\0.4.2\（约 8 MB，只需一次，和 PCL 自己装的一样）
· 双击后一直闪/留着黑窗口：已经修好了。旧版服务每秒用 tasklist 查陶瓦进程，
  在无窗口程序里会闪一下控制台；新版改成直接解析陶瓦启动输出里的端口，全程不再调用
  tasklist / netstat。如果还看到窗口，那是「启动主页服务.bat」自己的，
  双击 启动主页服务（无窗口）.vbs 或直接双击 PCL主页服务.exe 就没有了。
常见问题
--------
· 主页变成以前的样子（比如只剩一个「一键进服」）：说明主页服务没在运行，
  PCL 拉不到页面时会显示自己缓存的上一次内容。双击 启动主页服务.bat 或 PCL主页服务.exe，
  1 秒内就会恢复；再运行一次 安装开机自启.bat 可以避免下次重启又遇到。
· 主页显示“服务器离线”：确认 PCL主页服务.exe 在运行；浏览器打开
  http://127.0.0.1:8848/motd.xaml 应该能看到一段 XAML 文本。
· 正版账号进不去 / 提示验证失败：在你要玩的版本那一行点「正版」（on.imc.cab）；
  离线账号点同一行的「离线」（off.imc.cab）。两个按钮进的是同一台服务器。
· 主页顶部没有 Logo：确认 logo.png 和 PCL主页服务.exe 在同一文件夹，
  服务只从 exe 所在目录找这张图；换图后若还显示旧图，重启一次 PCL。
· 「按版本进服」列表是空的或只有一个版本：说明服务没找到 PCL 的版本目录。
  服务会自动找正在运行的 PCL（读取 PCL\Setup.ini 里的游戏路径）；
  还是找不到的话，把 src\motd_local_server.py 顶部的 PCL_DIR 改成 PCL 目录后重新打包。
· 朋友只有 1.12.2 / 1.16.5 之类：直接用列表里对应版本的按钮，服务器本身支持 1.8–1.21.11。
· 点「服务器官网」没反应：默认浏览器被拦截时，手动访问 https://imc.re。
· 安装补丁时报“文件被占用”：先完全退出 PCL（任务栏图标也要退出）。
· 杀毒软件报毒：PyInstaller 打包的单文件 exe 常见误报；源码在 src 里，
  也可以直接用 Python 运行 motd_local_server.py 代替 exe。
· PCL 自动更新后补丁会失效：更新完重新运行一次安装器。
· 折叠卡点了又自己弹回去：说明补丁还是旧版。双击发布包里的 PCL2-主页补丁安装器.exe 重新安装一次即可（新版补丁在刷新时只改文字、不重建控件）。
· 想改回原来的白色卡片：双击「关闭毛玻璃.bat」（约 1 秒生效）；
  也可以把同目录的 style.txt 内容改成 classic，改回 glass 就是毛玻璃。
· 毛玻璃效果不明显：在 PCL 设置里给启动器配一张背景图并开模糊，
  卡片背后越花哨，玻璃的通透感越强。
· 想改刷新间隔：在 PCL 文件夹的 PCL 子目录放 HomepageRefresh.txt，
  写 1s / 500ms / 60s 等，重启 PCL 生效。
· 想换回原来的主页：把 PCL\Setup.ini.bak 改名回 Setup.ini 即可。
· 想改官网地址 / 横幅高度 / 默认启动版本：改 src\motd_local_server.py 顶部的
  WEBSITE、BANNER、BANNER_HEIGHT、LAUNCH_VERSION，再重新打包（或用 Python 直接运行）。
· 想改状态卡标题显示的地址：改 src\motd_local_server.py 顶部的 STATUS_HOST；
  想让状态数据也从那个地址取，把 STATUS_QUERY 改成同一个域名（默认留空＝用 off.imc.cab 取，延迟最稳）。
· 按 F5 刷新主页后毛玻璃没了 / 卡片变回白色：旧版补丁只在第一次给卡片去白底，
  PCL 重建控件后新实例又带回白底。新版每次刷新都会重新套用样式，重新运行一次安装器即可。
· 数字卡住不动：先确认 PCL 目录里有 PCLPatch.dll（补丁装上了），再确认主页服务在运行；
  浏览器打开 http://127.0.0.1:8848/live.json 应该能看到一行带 status / motd / info 的 JSON。
· 主页设置成了「预设」而不是「联网更新」：预设里那份页面是写死在程序里的（本机自用实验），
  数字照样能刷，但版本列表不会跟着变；要回到联网版，去 设置 → 个性化 → 主页 选「联网更新」。
· 联机一直卡在「正在扫描节点 / 正在建立联机通道」：陶瓦靠 EasyTier 的公共节点中转，
  部分网络（尤其是校园网 / 运营商屏蔽）连不上 public.easytier.top:11010、
  public2.easytier.cn:54321，会一直超时。这不是补丁的问题，换个网络（手机热点）再试。
  EasyTier 日志在 %TEMP%\terracotta\ 里，能直接看到 connect to peer error: Timeout。
· 联机卡显示「陶瓦未启动」：直接点「创建房间」，会自动拉起陶瓦；若一直起不来，
  看同目录的 terracotta.log（记录下载 / 安装 / 启动失败原因）。
· 联机码复制不了：先点「创建房间」并完成局域网开放，卡片上出现联机码后
  「复制联机码」才有内容可复制。
