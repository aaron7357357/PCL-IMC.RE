# PCL IMC.RE

给 [IMC.RE](https://imc.re) 服务器玩家做的 PCL2 改版：主页是服务器实时状态面板，顶部多一个「联机」页驱动陶瓦（Terracotta）联机，**只有一个 exe**。

## 它做了什么

### 主页（启动页）

- **服务器状态卡**：在线/离线、MOTD、服务端版本、在线人数、延迟，每 0.5 秒刷新
- **内存优化**：清工作集 / 刷已修改页 / 清待命列表（管理员权限更彻底）
- **按版本进服**：自动扫描本机版本（读 `clientVersion`，整合包也认），只列 1.8 ~ 1.21.11
  - 排序：数字版本 → 英文整合包 → 中文整合包
  - `FileSystemWatcher` 盯着 `versions` 目录，装/删版本 1 秒内自动增删，没变化不重建
  - 「正版」走 `on.imc.cab`，「离线」走 `off.imc.cab`
- **加入 QQ 群**：imc公告群 `607355046` / imc聊天群 `1108248358` / 启动器交流群 `1135547472`
- **赞助商排行**、**赞赏制作者**（内嵌赞赏码，点击在启动器内放大）、**联系创作者**、**关于**

### 联机页（顶部导航）

| 分栏 | 内容 |
|---|---|
| 创建房间 | 填昵称 → 创建房间 → 游戏里 ESC → 对局域网开放 → 生成邀请码 |
| 加入房间 | 粘贴联机码 → 加入 → 游戏里自动多出服务器条目 |
| 设置 | 陶瓦路径（浏览/自动检测）、启动/停止组件、四个自动化开关 |

自动化：启动启动器时自动启动陶瓦、联机成功后自动写 `servers.dat`、退出时停止陶瓦、首次使用自动下载陶瓦。

## 快速开始

1. 解压到单独文件夹（**不要在 `Program Files`、`Documents` 这类目录**，PCL 会因目录不可写而拒绝启动）
2. 双击 `Plain Craft Launcher 2.exe`
3. 第一次启动会自动把主页预设切成「imc.re主页」、标题栏改成 `PCL IMC.RE`

> 想重新触发：删掉 `PCL\imc-preset-once.txt` 和 `PCL\imc-brand-once.txt` 再启动。

## 实现结构

```
Plain Craft Launcher 2.exe（官方 2.13.1.1 + ILRepack 合并补丁）
  ├ PCLPatch.dll 的代码已内联
  ├ ImcNative.cs   服务器状态（SLP）/ 内存优化
  ├ TcNative.cs    陶瓦启动 / 状态 / NBT 写 servers.dat
  ├ IMCHome.xaml   主页（内嵌资源）
  └ TCHome.xaml    联机页（内嵌资源）
```

构建：`src\build-single.ps1`（编译 → ILRepack 合并 → SelfLink 重接调用 → 部署）。

页面 XAML 只加载一次，之后补丁只改带 `Tag="live:xxx"` 的控件文字，折叠状态与滚动位置不会被刷新重置。

## 常见问题

**主页没变成 IMC 那套？**
设置 → 个性化 → 主页 → 预设，选「imc.re主页」。

**主页空白 / 启动器打不开？**
基本是目录不可写（PCL 的权限检查）或 exe 被改名。放到普通文件夹再试。

**陶瓦按钮没反应？**
联机 → 设置 → 点「自动检测」，或「浏览」手动选 `terracotta.exe`，也可以点「启动组件」触发自动下载。
